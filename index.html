    Como usar

    1. 1
      Abra um Codespace

      Clique em Abrir no Codespaces. O GitHub cria um ambiente Linux na nuvem com o repositório pronto.

    2. 2
      Solte seu arquivo no Codespace

      Arraste o script para a árvore de arquivos (ou use Upload… no menu). Coloque na raiz do projeto.

    3. 3
      Rode o comando gerado acima

      Cole no terminal do Codespace. O deob.py baixa o runtime Luau, executa o script em ambiente simulado e devolve o resultado.

    4. 4
      Baixe o resultado

      O arquivo final fica em output/<nome-do-script>. Clique com o botão direito → Download.

    Prefere rodar local?

    Clone o repositório, instale Python 3.10+, e rode python deobf/build_luau.py uma vez para baixar/compilar o runtime. Depois é só python deob.py seu_script.luau.

    Feito para uso educacional e pesquisa. Respeite os termos de uso dos scripts que analisar.
